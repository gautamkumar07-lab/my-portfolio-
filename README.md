## 🚀 Quick Start & Local Development

### 1. Clone the repository
```bash
git clone https://github.com/gautamkumar07-lab/gautam-portfolio.git
cd gautam-portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start development server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 4. Build for Production
```bash
npm run build
```

## 🌐 Deploy to Vercel (1-Click)

1. Push this repository to your GitHub account (`https://github.com/gautamkumar07-lab/gautam-portfolio`).
2. Log in to [Vercel](https://vercel.com) and click **"Add New Project"**.
3. Import `gautam-portfolio`.
4. Keep the default settings (Framework Preset: **Vite**, Root Directory: `./`).
5. Click **Deploy**. Your portfolio will be live in under 60 seconds with automated CI/CD on every git push!
