## 🚀 Getting Started

### Prerequisites

- Node.js (v18+ recommended)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/gautamkumar07-lab/gautam-portfolio.git

# Navigate to project directory
cd gautam-portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

The application will be live at `http://localhost:3000`.

### Production Build

```bash
npm run build
```
